PROJECT NAME: Student Career Recommendation System

PROJECT OVERVIEW: 

This is a beginner-friendly Python Program which allows students to get relevant career path suggestions based on their skills. The user enters their name and the skills they have after that their skills are matched with 20 pre-defined career paths and the match percentage of relevant careers are showed

TECHNOLOGIES USED:

1.Python

2.OOP

3.List

4.Dictionary

5.Loops

6.Conditional statments

7.Class

8.Inheritance

9.Modules


WORKING OF PROGRAM:
1. Add your name
2. Add your skills
3. Your skills are matched with the skills required for different careers
4. Those careers are displayed as the output with whom you have 50% or more match rate

HOW TO RUN:
1. Clone the repository

git clone https://github.com/sfaizyab2006/Student-Career-Recommendation-System.git

2. Open the project folder

cd Student-Career-Recommendation-System

3. Run the program

python main.py
